# Capability card photography

All six images are from Unsplash and used under the [Unsplash License](https://unsplash.com/license),
which permits commercial use without attribution. Credit is recorded here anyway so the
source of every asset in the repository is traceable.

Each file was cropped to 880×760 and re-encoded to WebP at the point of download.

| File | Card | Photographer | Source |
| --- | --- | --- | --- |
| `message.webp` | Message and email checks | Brett Wharton | https://unsplash.com/photos/vMuA-OoDReo |
| `indicators.webp` | Links, numbers and addresses | Agence Olloweb | https://unsplash.com/photos/d9ILr-dbEdg |
| `report.webp` | Reports Council can act on | Markus Winkler | https://unsplash.com/photos/Q2J2qQsoYH8 |
| `map.webp` | Scam map for Hume | Shanjir H \| Photo4life AU | https://unsplash.com/photos/h5j56dfLlKo |
| `alerts.webp` | Verified alerts, not rumours | Oleg Laptev | https://unsplash.com/photos/QRKJwE6yfJo |
| `recovery.webp` | Recovery guidance | Taylor Grote | https://unsplash.com/photos/L3qUP8MpExc |

`message.webp` is cropped below the top of the phone screen deliberately: the uncropped
frame shows a legible sender number, and a real number displayed on a scam-detection card
reads as an accusation against whoever holds it.
